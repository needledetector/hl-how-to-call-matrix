# 呼称マトリクス

Google スプレッドシートの「呼称表」「補助データ」「軸マッピング」を読み込み、誰が誰をどう呼ぶかを表示する静的な PWA です。フレームワークやビルド工程はありません。

## 起動

このディレクトリで `python -m http.server 8000` を実行し、`http://localhost:8000` を開きます。ES Modules を使うため、HTML を `file://` で直接開かず HTTP サーバー経由で表示してください。本番では HTTPS と、`.mjs` を JavaScript の MIME タイプで配信できるサーバーが必要です。

## 構成

| ファイル | 役割 |
| --- | --- |
| `index.html` / `style.css` | 画面構造とスタイル |
| `app.js` | 描画、操作、絞り込み用 CSS、URL による表示状態の保存・復元 |
| `data.mjs` | シート取得、CSV・呼称記号の解析、表示データの組み立て |
| `search.mjs` | 日本語検索の正規化、呼称・セルの判定、空の行列の判定 |
| `sw.js` | アプリ本体と取得済みシートのキャッシュ |
| `convert.py` | Excel から予備の `data.json` を生成する変換ツール |

接続するシートの ID とシート名は `data.mjs` にあります。シート取得に失敗すると `data.json` を試しますが、このリポジトリには同梱されていません。必要に応じて `convert.py` で生成・配置してください。

## 検索・絞り込み

- 上部の「呼ぶ人」「呼ばれる人」を別々に選べます。入れ替えボタンで方向を反転できます。両側の人物範囲をまとめて変える場合は、絞り込み内のグループ・期生・人物選択を使います。
- スマホ幅（640px以下）では「一覧」、それ以外では「表」を初期表示します。形式はいつでも切り替えられ、URLにも保存されます。一覧は条件に一致する記録を40組ずつ表示し、未調査の組み合わせは表で確認できます。
- 絞り込みは「指定なし／限定／除外」を明示的に選択します。列幅・行数制限などは別の「表示設定」にあります。スマホではパネルが画面下に開き、「完了」で閉じます。
- ひらがなを含む検索はカタカナ表記にも一致します。カタカナのみの検索では、ひらがなと区別します。英字の大小・全角半角・空白は正規化します。
- 検索件数は人物範囲・絞り込みに一致する呼称のみを数えます。↑↓で一致セルを移動でき、一覧では必要に応じてページも切り替わります。検索語もURLに保存します。
- 呼称フラグと軸の「限定」は OR 条件で、いずれかに一致すると残ります。「除外」はそれより優先します。
- 状態の除外は注記を対象とし、同じセルに呼称がある場合は呼称側の条件で判定します。
- 「空の行列を隠す」は、選択中の人物間で条件に一致するセルがある行・列をそれぞれ残します。

## 検証

Node.js 24 で `node --test tests/*.test.mjs` を実行します。追加パッケージは不要です。CSV、呼称記号、シート構造の異常、日本語検索、絞り込み、Service Worker のキャッシュを検証します。キャッシュのテストはブラウザー API の代替実装を使用するため、実ブラウザーでの PWA 動作確認は別途必要です。

`node tests/browser.mjs` で Chrome / Edge のヘッドレス UI テストを実行できます。Windows の標準インストール先から検出し、それ以外の場合は実行ファイルのパスを引数または `CHROME_PATH` で指定します。テスト用シートでスマホの縦横画面・PC画面、方向別選択、検索件数、ページ送り、URL復元、詳細画面を検証し、一時ディレクトリにスクリーンショットを保存します。実データのシートにはアクセスしません。iOS Safariなど実機固有の挙動は別途確認してください。

## 更新とオフライン

アプリを更新するときは `sw.js` の `CACHE` の版番号を上げ、新しい必須ファイルを `ASSETS` に追加します。必須ファイルをすべて取得できた場合だけ、新しい Service Worker が有効になります。更新後はページを再読込してください。

シートはネットワーク優先で取得し、失敗時は同じシートの取得済みキャッシュを使います。初回アクセスや新しいキャッシュへの切り替え後は、オンラインでシートを取得する必要があります。
